# 🧪 Laureano - Testing QA Showcase

Bienvenido a mi portfolio de pruebas de software. Aquí demuestro mis habilidades prácticas como **QA Tester**.

## 📌 Sobre mí

Soy Laureano, un apasionado del testing de software con enfoque en calidad y experiencia de usuario. Este portfolio muestra mi trabajo real en:

- ✅ Pruebas manuales (casos, bugs, checklists)
- ✅ Testing de APIs con Postman  
- ✅ Consultas SQL para validación de datos
- 🚀 Automatización en progreso (Python + Selenium)

## 🎯 Proyecto demostración

Todos los ejemplos están basados en **SauceDemo** (https://www.saucedemo.com/), una tienda de prueba gratuita.

**¿Por qué esta app?**
- Pública y accesible para cualquiera
- Flujos reales (login, compras, carrito)
- Me permite mostrar bugs controlados
